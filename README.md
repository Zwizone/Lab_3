# Калькулятор на C#

## Описание
Простое консольное приложение на языке C# для выполнения базовых арифметических операций (сложение, вычитание, умножение, деление).

## Установка и запуск
Склонируйте репозиторий:
   git clone <https://github.com/Zwizone/Lab_3.git> cd <Lab_3>
Запустите проект:
   dotnet run

## Требования
* .NET Core 6.0 или выше
